# JIWU-Pandora 2.9.7

- UMI 四路采集使用 2×2 预览；原六路配置完整保留为 UMI数据采集_gt.json，两份配置首次升级自动加入收藏。
- 新增脚踏单击语音：录制中交替播报开始／结束提示，调整姿态后暂停 2 秒，再播报静止提醒和倒计时。
- 每次 Start Recording 独立计时，45／55 分钟语音提醒，60 分钟自动停录；停止后再次开始会重新计时。
- 更新区合并为一个按钮，随检查、下载、取消、重试和安装阶段切换文字；安装前再次校验，通过系统授权执行升级。
- 安装包改为实验室局域网分发，修复新脚踏设备读取权限规则，并区分下载服务未连接与尚无版本清单。

## 使用与兼容性

四路 UMI 预设移除 gt_l、gt_r 及对应相机绑定；需要 GT 数据时选择 UMI数据采集_gt.json。GT 文件是原配置逐字节副本，保留原按钮动作。四路预设脚踏为 CC_DSK_8152F77E74BF、键码 22、单击 umi_speech、双击 none；换设备时按实际序列号绑定。

语音使用包内离线 WAV 与现有 EGO SDK 相机连接，不使用系统默认声卡。踏板语音不切换录制、不写 tag；停止录制会取消待播请求。语音故障不会阻止 60 分钟停录。计时按一次 Start/Stop，存储分片不重置计时。

更新固定访问 http://192.168.110.25:8765/latest.json，不回退 GitHub；旧版客户端需手动安装本版才能使用新的局域网更新。升级前结束录制、回放与设备会话；安装成功后重新打开客户端。

## 下游适配

新增配置动作值 umi_speech，只支持单击且双击必须为 none。下游配置校验若枚举按钮动作，应加入该值。原始记录格式和 tag/photo 事件编码未改变；使用四路预设的消费者不得再要求 gt_l、gt_r，仍需六路数据的任务请选择 GT 预设并使用匹配的 task name。自定义工位配置继续保留，不强制覆盖。
